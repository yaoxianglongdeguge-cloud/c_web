c_web is running

纯 C 从零实现的 HTTP/1.1 服务器：半同步/半异步线程模型 + 内存池 + 有序发送 + sendfile 零拷贝。

状态检测中… 监听 127.0.0.1:5343

Receiver / Worker 双线程

收发线程负责 accept、epoll、读包与保序发送；业务线程负责解析、路由与构造响应，靠全局任务队列解耦。

请求保序

同一连接上响应按 serial 递增顺序发出，应用层可以乱序处理、框架保证有序回包。

状态机拆包

暂存区 + 状态机处理粘包/半包，请求超过暂存区时自动扩容，超大请求回 413。

分级内存池

响应头/体自动从内存池分配，池满降级 503，跨线程内存经队列归还，绝不跨线程 free。

sendfile 零拷贝

静态文件直接 sendfile 到 socket，10MB 文件下载不用进用户态缓冲区。

错误响应

400 / 404 / 405 / 408 / 413 / 414 / 431 / 500 / 503 自动生成文本响应。
