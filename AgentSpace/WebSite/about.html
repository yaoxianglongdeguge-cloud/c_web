关于这个服务器

本页与首页都是磁盘上的静态文件，由框架用 sendfile 零拷贝发出； 页面里的接口数据则来自 WebApp/WebApp.c 注册的动态路由。

一次请求的生命周期

accept → epoll → 读入暂存区 → 状态机判定完整请求 → 投递任务队列 → 业务线程解析 URL/Query/Header → RouterHandlerFind(url) → 业务函数写 Response → 打包 Response → 按 serial 保序发送 → 内存归还。

应用层怎么写

void handler(Request*, Response*)，里面用 RequestGetter() 读参数、ResponseBodySet() 写文本、 ResponseHeaderSet() 写头、ResponseFileSet() 发文件。

本页用到的路由

GET /、GET /about、GET /style.css、 GET /app.js、GET /hello、GET /time、 GET /echo、POST /api/echo、GET /api/info、 GET /mem/256k、GET /download/10mb。

想验证 404 / 405？

访问 /no-such-route 得到 404（未注册路由）； 访问 GET /api/echo 得到 405（该路由只允许 POST）。
